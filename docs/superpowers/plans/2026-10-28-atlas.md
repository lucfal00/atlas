# Atlas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> Il comportamento di ogni schermata è nella spec (sezioni citate); qui firme, casi di test con valori attesi e criteri di accettazione. Il codice non è duplicato nel piano.

**Goal:** PWA offline per luoghi visitati e da visitare, viaggi con costi, diario, su un atlante disegnato; dati sincronizzati cifrati in un repository GitHub privato.
**Architecture:** HTML/CSS/JS ES modules senza build, base copiata da Habits. Calcoli puri in `js/logic.js`, `js/geo.js`, `js/merge.js`; IndexedDB solo in `js/db.js`; documento solo in `js/store.js`; mappa SVG in `js/map.js`; una vista per file in `js/views/`. Confini preparati una volta da `scripts/build-geo.mjs`.
**Tech Stack:** HTML, CSS, JS (ES2022), Service Worker, IndexedDB, WebCrypto, CompressionStream, Pointer Events, GitHub REST API, Nominatim, `node --test` (Node 24).
**Spec:** `docs/superpowers/specs/2026-10-28-atlas-design.md`

## Global Constraints

- Nessuna dipendenza esterna, nessun build step (lo script geo gira solo in sviluppo; i risultati sono nel repository).
- Date locali `YYYY-MM-DD`, mai UTC. Importi in euro.
- UI in italiano; input testo `font-size ≥ 16px`; target tocco ≥ 44 px.
- Tutto il testo utente/import/rete passa da `esc()`; colori da `safeColor()`; URL dei link solo `http:`/`https:`.
- IndexedDB `atlas` v1, store `doc`, `meta`; nessuna chiave `localStorage`; cache SW con prefisso `atlas-`.
- `logic.js`, `geo.js`, `merge.js` senza DOM, rete, storage.
- Accento `--accent #c2410c`, `--accent-strong #9a3412`, scuro `#f0a07a` con `--on-accent #0f1117`; in programma `#2563eb` (scuro `#60a5fa`). (Terracotta, scelto dall'utente il 2026-10-28, prima verde acqua.)
- Nominatim: solo al tocco su Cerca, ≤ 1 richiesta/s, `accept-language=it`.
- Server locale porta **8082**.
